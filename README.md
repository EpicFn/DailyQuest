# Daily Quest · 데일리퀘스트

매일 반복할 일을 퀘스트로 관리하고, 달력에서 달성 기록을 확인하는 오프라인 앱입니다.

## 사용 방법

1. **퀘스트 관리**에서 카테고리를 선택하고 퀘스트를 추가합니다. 진행 중·전체·카테고리별로 목록을 볼 수 있으며, 퀘스트 수정·삭제·활성화 상태 변경도 가능합니다.
2. **오늘의 도전**에서 카테고리별 퀘스트를 완료 체크하고 오늘의 달성률을 확인합니다.
3. **도전 기록**에서 날짜를 눌러 해당 일의 기록을 확인합니다. 상단 연월을 누르면 원하는 달로 이동합니다. 날짜 숫자의 채움은 달성률을, 별은 100% 달성을 나타냅니다.
4. 상단 **백업 및 복원** 메뉴에서 기록을 파일로 저장하거나 복원합니다. 복원하면 현재 기록을 백업 내용으로 교체합니다.

카테고리는 목록 끝의 **+**로 추가하고, 직접 만든 카테고리를 선택해 이름을 바꾸거나 삭제할 수 있습니다. 퀘스트를 변경해도 이미 생성된 과거 기록은 유지됩니다.
