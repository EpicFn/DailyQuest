# Daily Quest · 데일리퀘스트

매일 반복할 퀘스트를 관리하고, 달성 기록을 확인하는 오프라인 모바일 어플리케이션

## 사용 방법

1. **퀘스트 관리**
- 카테고리를 선택하고 퀘스트를 추가
- 진행 중·전체·카테고리별 목록
- 퀘스트 수정·삭제·활성화 상태 변경 가능

2. **오늘의 도전**
- 완수한 퀘스트를 완료 체크
- 오늘의 달성률을 확인

3. **도전 기록**
- 날짜별 달성률을 확인
- 날짜를 눌러 해당 일의 기록을 확인

4. **백업 및 복원** 
- 기록을 파일로 저장하거나 복원
- 복원하면 현재 기록는 백업 내용으로 교체

## 기술 스택
